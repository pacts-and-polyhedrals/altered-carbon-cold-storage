# Cold Storage: The Faces We Left Behind

A Foundry VTT v14 adventure module for the **Altered Carbon RPG — Unofficial** system.

**Module ID:** `cold-storage`  
**Version:** `1.0.0`  
**Required system:** `altered-carbon-rpg` v1.0.0 or newer  
**System manifest:** `https://raw.githubusercontent.com/pacts-and-polyhedrals/altered-carbon-rpg-foundry/main/system.json`

## What it contains

- 8 pregenerated characters for a six-player selection
- 40 archived/former sleeves
- 20 recurring contacts
- 160 relationship links
- 6 factions
- 19 core journals
- 8 canonical pregen loadouts
- 4 principal adversaries
- essential revelation redundancy with at least 3 independent clue channels
- GM setup tool and relationship dashboard
- player-facing relationship board
- placeholder scenes for the full one-shot flow
- Project Palimpsest branding asset

The module uses source-controlled JSON and imports its adventure Documents into a world when the GM chooses **Cold Storage Setup → Import / Update Cold Storage**.

## Installation

Install the Altered Carbon system first, then install this module with:

`https://raw.githubusercontent.com/pacts-and-polyhedrals/altered-carbon-cold-storage/main/module.json`

Enable **Cold Storage: The Faces We Left Behind** in a world using the `altered-carbon-rpg` system.

## Adventure premise

Bay City, 2384. Eight DHFs awaken in unfamiliar sleeves with memories that end in 2274. A century has passed, two resleeving bays are empty, and somebody is coming to recover their stacks intact. Their old investigation into **Project Palimpsest** — a programme capable of altering continuity, memory, identity and testimony — was never truly buried.
