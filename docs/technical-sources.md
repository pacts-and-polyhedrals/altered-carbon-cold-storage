Checked 11 September 2026. Only official Foundry documentation was used for technical API guidance:

- JournalEntry API, Version 14: https://foundryvtt.com/api/v14/classes/foundry.documents.JournalEntry.html
- JournalEntryPage API, Version 14: https://foundryvtt.com/api/v14/classes/foundry.documents.JournalEntryPage.html
