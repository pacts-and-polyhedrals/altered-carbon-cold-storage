# IP and Distribution

Cold Storage: The Faces We Left Behind is original adventure material created for use with an unofficial Altered Carbon RPG Foundry system.

Do not include source rulebook PDFs in this repository or in GitHub release assets. The module expects the separately installed `altered-carbon-rpg` system to provide the underlying game mechanics and reference catalogs.

Public distribution of a fan project can involve trademark, copyright and licensing considerations. The repository therefore carries no claim of official endorsement and should not present itself as an official Altered Carbon product.
